# Directions

Den här katalogen innehåller alternativa helhetsgrepp om
*Anomaliernas kosmologi*.

En direction är inte kanon.

Den beskriver en möjlig version av hela romanen:
- vad romanen egentligen handlar om
- vilken berättelsebåge som bär boken
- vilka teman som är centrala
- vilka spår som tonas ned eller tas bort
- hur metafysiken fungerar
- vilken litterär ton och ambitionsnivå versionen har
- hur slutet omkring år 2100 relaterar till resten

Flera directions får existera parallellt och motsäga varandra.

Syftet är att kunna pröva olika romaner mot samma råmaterial utan
att skriva om eller förstöra fragmenten.

## Relation till övriga repot

notes/fragments/
    Råmaterial, minnen, idéer och scener.

story_bible/
    Etablerade interna sanningar och kontinuitet.

production/
    Hur materialet litterärt renderas.

directions/
    Alternativa helhetsgrepp om vilken roman materialet kan bli.

manuscript/
    Den version som faktiskt håller på att komponeras.

En direction blir inte automatiskt story_bible eller manuscript.
Den måste först väljas eller användas som arbetsmodell.
