# Anomaliernas kosmologi

Ett levande manus och en litterär produktionsverkstad.

> Författaren äger idéerna. Verkstaden bygger världen omkring dem.

## Grundstruktur

Projektet består av flera nivåer:

1. `notes/fragments/` – råmaterial, scener, minnen, idéer och YAML.
2. `story_bible/` – romanens värld, karaktärer, filosofi och kontinuitet.
3. `production/` – arbetsmetoden: hur fragment får renderas till litteratur.
4. `manuscript/` – produktionslager för indexerade fragment, scener och kapitel.
5. `output/` – genererade helheter: läsutgåvor, PDF, Obsidian och webbrenderingar.

Princip: inget kastas. Allt kan återvinnas, indexeras eller renderas på nytt.

## Produktionsprincip

Anomaliernas kosmologi skrivs inte som en ensam linjär text från början till slut.

Den produceras.

Författaren fungerar som regissör och kreativ ledare för en litterär verkstad. Fragment och YAML kan vara råa, muntliga, filosofiska eller ofullständiga. När materialet renderas till scen eller kapitel läser verkstaden produktionskontraktet i `production/` och romanens sanningar i `story_bible/`.

Det innebär att AI får bygga fysisk värld, dialog, rytm, övergångar och scenisk närvaro, men inte ändra bokens kärna: erfarenheterna, etiken, Ghana, Solvinter, relationerna och de bärande idéerna.
