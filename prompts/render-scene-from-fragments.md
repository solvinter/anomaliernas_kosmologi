# Render Scene From Fragments

Use this prompt when converting one or more fragments into a literary scene.

## Instruction

Read:

1. the selected source fragments
2. any companion YAML
3. `manuscript/fragments_index.yaml`
4. relevant files in `story_bible/`
5. `production/creative_contract.md`
6. `production/rendering_contract.md`
7. `production/expansion_policy.md`
8. `production/literary_principles.yaml`
9. `production/cinematic_guidelines.md`
10. `production/film_manifesto.md`
11. `production/quality_checklist.md`

Then create a rendered scene.

## Requirements

- Preserve the author's core idea.
- Preserve sacred material listed in the scene file or YAML.
- Build physical reality where the fragment is abstract.
- Add sensory anchors only when they serve the scene.
- Prefer scene over essay.
- Let philosophy appear through people, pressure, questions and action.
- Report what was expanded, compressed, moved or cut.

## Output

Return:

1. rendered scene
2. source fragments used
3. expansion notes
4. continuity questions
5. suggested chapter placement
