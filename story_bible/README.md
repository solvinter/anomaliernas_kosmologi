# Story Bible

`story_bible/` describes what is true inside Anomaliernas kosmologi.

It is not output and not raw manuscript.

It is the reference layer used when fragments and YAML are rendered into scenes, chapters and reading copies.

## Structure

- `characters/` contains durable character truths.
- `world/` contains places, institutions, social worlds and future-state assumptions.
- `philosophy/` contains recurring conceptual structures.
- `solvinter/` contains the Solvinter model as it exists in the fiction.
- `chronology/` contains timeline and arc constraints.
- `recurring_details.yaml` contains motifs, objects and sensory anchors that should recur.

## Rule

If a fragment contradicts the story bible, do not silently fix it.

Flag the contradiction for author review unless the fragment is clearly older than the current canon.
